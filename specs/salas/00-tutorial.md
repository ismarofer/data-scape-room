# Sala 0 · Tutorial (R0) — «Prólogo»

**Objetivo:** aprender la pantalla y a pedir ayuda. **~8 min** (5 de historia y guía de pantalla + 3 del nivel). Contenido: `content/rooms/R0.yaml`, `content/locks/p0_tutorial.yaml`.

**Briefing:** el hospital (Costa Atlántica), la cita de las 13:00; viñetas: conocer la pantalla, abrir el primer candado, pedir ayuda a Lumi.

## Nivel 1 · El primer candado (`p0_tutorial`, código)
| | |
|---|---|
| Qué hace el alumno | Escribe el océano que baña la costa del hospital. |
| Información en la pantalla del nivel | **La misión nombra el hospital** («Trabajáis en el Hospital Costa Atlántica, … costa oeste de Galicia»). Antes la pista solo estaba en el briefing y en la historia, que ya no se ven al resolver: el alumno no tenía de dónde sacarla (fallo detectado el 23-nov). |
| Cómo se resuelve | Leer la misión → escribir el océano en «Vuestra respuesta» → «Probar». |
| Si falla | «No es correcto». Se desbloquea la pista 2 (1 intento). |
| Ayudas | 1 «releed la misión: el nombre del hospital lleva el océano», 2 al oeste de Galicia, 3 «ATL, 8 letras», solución. |
| Dificultad 16 años | 1/5. Es calentamiento: lo importante es ver dónde están las cosas y probar a Lumi. |
| Tiempo | 2-3 min. |
| Probado | e2e (speedrun, guía, Lumi y pistas) + unit (escalera completa sobre este nivel). |

**Por qué este nivel enseña la escalera:** aquí se aprende lo que cuesta la ayuda sin arriesgar nada difícil; el e2e «guided experience» hace una pregunta rápida (aviso −1) y pide la pista 1 (aviso «Confianza de la Comisión −5»).

**Regla que sale de este nivel (vale para los 20):** todo lo necesario para resolver un nivel está **en la pantalla de ese nivel** (misión, pasos, herramienta o tarjetas). El briefing y la historia ambientan, pero no pueden ser la única fuente de un dato. Ver [UI 01](../ui/01-experiencia-general.md#principios).
